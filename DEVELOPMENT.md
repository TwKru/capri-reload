# Как дорабатывать Capri Reload

## Как проходит запрос

`Микрофон → voice.Listener → main.Capri → intent_router.IntentRouter → исполнитель → voice.Speaker`

Текст из меню попадает сразу в `main.Capri`. Имя открывает окно прослушивания,
«стоп» отменяет обработку без ожидания ИИ. Каждый принятый запрос сначала получает
мини-модель `qwen3:0.6b`. Она возвращает структурированное решение, а не исполняемый код.

- Команда → `Actions.handle()` разбирает исходную фразу. Если обычный разбор не помог,
  типизированное решение мини-ИИ исполняется через `Actions.execute_decision()`.
- Разговор → локальный характер или разговорная модель `qwen3:8b`.
- Подтверждение и выбор программы → проверяются исходные слова пользователя.
- Если мини-модель выключена, прогревается или недоступна → резервный обычный разбор.

## Карта проекта

| Файл или папка | Что здесь менять |
|---|---|
| `main.py` | Запуск, очередь запросов, имя/стоп, маршрутизация, соединение сигналов с аватаром, меню в трее. `DEFAULTS` — исходные настройки. |
| `actions.py` | Команды и их выполнение. `Actions.routes` — фразы, методы класса — исполнители, `Reply` — результат. `AppIndex` — поиск установленных программ. |
| `intent_router.py` | Мини-ИИ: `SYSTEM` — инструкция, `ACTIONS` и `SCHEMA` — допустимые решения, `Decision` — проверка параметров. |
| `local_ai.py` | Разговор с Ollama, история, потоковая выдача предложений, обработка ответа. |
| `ai.py` | Необязательный внешний ИИ; в обычной локальной конфигурации выключен. |
| `voice.py` | Микрофон и распознавание (`Listener`), озвучка и эффекты (`Speaker`), запасной голос Windows. |
| `kokoro_voice.py` | Дополнительные локальные голоса Kokoro; исходная Светлана работает через `voice.py`. |
| `persona.py` | Общая инструкция характера, готовые реплики `LINES`, редкие разговорные варианты, обращение к пользователю. |
| `personality.py` | Настроение, обида, примирение, реакции на похвалу и грубость. |
| `dismissal.py` | Отличает просьбу спрятаться от отрицания, цитаты и упоминания слова. |
| `avatar.py` | Окно поверх программ, отрисовка, анимации, перемещение, реакции на мышь. |
| `assets/poses/` | Статичные исходные позы; `capri_roam.png` — лежачая поза ожидания и запасная поза прогулки. |
| `assets/anim/<имя>/` | Покадровые PNG-анимации. |
| `assets/motion_sources/` | Исходные листы собственных анимаций ходьбы и вращения. |
| `assets/desktop_sprites/` | Оставшиеся импортированные клипы: улыбка, перетаскивание, сон, пробуждение, танец. Лицензия — в этой папке. Циклы стояния и моргания удалены. |
| `media.py` | Управление музыкальными и видеосессиями Windows. |
| `program_lookup.py` | Поиск полного названия программы по сокращению в интернете. |
| `automation.py` | Цепочки действий и автоматизация интерфейса. |
| `gamma.py`, `game_mode.py` | Гамма монитора и определение игрового режима. |
| `entries_dialog.py`, `sound_dialog.py`, `profile_dialog.py` | Окна пользовательских настроек. |
| `updater.py` | Обновление из `TwKru/capri-reload`, проверка и установка файлов, перезапуск. |
| `tools/`, `setup*.bat`, `run.bat` | Установка, подготовка моделей и ассетов, запуск. |
| `tests/` | Проверки команд, маршрутизации, звука, анимаций, безопасности и обновлений. |

`config.json` содержит личные настройки. `capri.log` и `capri-crash.log` помогают
искать ошибки; `.capri-version` хранит установленную версию. Их не нужно вручную
переносить в чужую установку или включать в коммит вместе с личными данными.

## Добавить сайт, программу или свой ответ без изменения кода

Открой меню в трее → «Мои сайты, программы и ответы…». Там можно добавить имя и
адрес сайта, программу или ответ на свою фразу. Эти списки сохраняются в `config.json`;
они также доступны в разделах `sites`, `apps`, `app_aliases`, `replies`.

## Добавить голосовую команду

Пример команды «покажи статус», которая пока только отвечает текстом:

1. В `Actions.__init__()` добавь в `self.routes` перед общими шаблонами:

   ```python
   (r"^(покажи статус|статус системы)$", self.status),
   ```

2. В класс `Actions` добавь исполнитель:

   ```python
   def status(self, c, m):
       return Reply("Я на связи. Команды доступны.")
   ```

   `c` — исходная нормализованная команда; `m` — совпадение регулярного выражения.
   `Reply.text` озвучивается, `Reply.action` может запускать реакцию интерфейса.

3. В `intent_router.SYSTEM` укажи, что просьба показать статус относится к `command`.
   Для этого варианта не нужно расширять JSON-схему: обработчик получит исходную фразу.
   Чтобы поддержать новый отдельный тип решения мини-ИИ, согласованно добавь его
   в `ACTIONS`, проверку `Decision.parse()` и `Actions.execute_decision()`.

4. Если нужен постоянный текст с вариантами, добавь ключ в `persona.LINES`
   и используй `line("ключ")`. Параметры передавай через `line("ключ", t=название)`.

5. Проверь запрос вручную через «Написать команду…», затем голосом с именем Капри.
   Новые команды перечисляй в `КОМАНДЫ.md`.

Для действий с последствиями используй существующий механизм `self.pending` и
ответ `Reply("Подтверждаешь?", "ask")`, как в команде `power`.
Подтверждение проверяет `Actions.handle()`; текст, придуманный моделью, его не заменяет.
Долгую работу не выполняй в Qt-обработчиках мыши, отрисовки или таймера — запросы
выполняет рабочая очередь `Capri.jobs`. Внешние программы запускай списком аргументов;
не превращай вывод ИИ в командную строку.

## Добавить анимацию

1. Создай `assets/anim/celebrate/` и положи прозрачные PNG одного размера:
   `0000.png`, `0001.png`, `0002.png` и далее. Имена сортируются по алфавиту.
   Используй одинаковый холст и положение персонажа, чтобы он не дёргался между кадрами.
2. `load_anims()` подхватит папку при следующем запуске. Обычные клипы играют
   с `ANIM_FPS = 24`; параметры существующих плавных клипов смотри в их `motion.json`.
   Промежуточные кадры в этой реализации смешиваются, а не дорисовывают движение.
3. Из команды верни:

   ```python
   return Reply("Смотри!", "anim:celebrate")
   ```

   `main.Capri` передаст имя в `Avatar.play_anim()`. Внутри кода аватара можно вызвать
   `self.play_anim("celebrate", loop=True)` для цикла; для такого клипа предусмотрите
   условие остановки, чтобы он не перекрывал остальные состояния.
4. Для преобразования своего видео есть инструмент:

   ```powershell
   python tools/convert_anim.py "C:\clips\celebrate.mp4" celebrate green
   ```

   Последний аргумент — фон для удаления (`green`, `black` или `white`).
   Он создаёт кадры в папке проекта. Проверяй края волос и тёмные детали после конвертации.

Позы ожидания выбираются в `Avatar._figure()`, режимы — в `set_mode()`, а движение
по экрану — отдельно от частоты кадров. Лежачая поза ожидания не включает `sleeping`:
Капри продолжает слушать имя. Для новых сторонних ассетов сохраняй их условия и уведомления.

## Изменить голос или характер

Голос, скорость и эффекты настраиваются через меню звука и параметры `config.json`.
Обработка сигнала находится в `voice.py`. Не меняй голос через системный промпт ИИ.

Для манеры разговора меняй `persona.CHARACTER`, для готовых ответов — `LINES`,
для настроений и реакций — `personality.py`. Мини-диспетчер не должен сочинять ответы:
его задача — выбирать маршрут и параметры действия.

## Проверить и сохранить изменения

Запускай из корня рабочей копии, тем же Python, которым запускаешь Капри:

```powershell
python -m unittest discover -s tests -q
python -m ruff check . --select E9,F
git diff --check
```

Для команды с параметрами проверь диапазоны, отрицание, вопрос об этой команде и
отмену. Для анимации — возврат в ожидание, «стоп», игровой режим и расход памяти.
Сетевые и системные действия в автоматических тестах подменяй через `unittest.mock`.
После изменения исходников перезапусти Капри. Обновления пользователей берутся из
GitHub, поэтому готовые изменения нужно закоммитить и отправить в репозиторий.
