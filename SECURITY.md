# Безопасность Capri Reload

Проверка кода от 29 октября 2026 года охватывает запуск приложений, ответы диспетчера ИИ,
ссылки, установку обновлений и моделей, воспроизведение речи и установленные Python-зависимости.

Исправлены следующие проблемы:

- Запасной запуск пользовательских приложений использовал командную оболочку. Теперь команда
  передаётся процессу напрямую с `shell=False`, без обработки `&`, `|` и перенаправлений оболочкой.
- Ссылки, включая сохранённые адреса вкладок, принимаются только с `http`/`https`, без учётных
  данных и управляющих символов. Произвольные URI-обработчики через команду сайта не запускаются.
- Диспетчер ИИ не может открыть программу, не названную в запросе. Потеря цели команды mute
  больше не превращает выключение звука одной программы в выключение всего звука Windows.
- Установщик обновлений отклоняет служебные имена Windows, имена с конечными точками/пробелами,
  повторяющиеся пути с разным регистром и пути через локальные ссылки к защищённым файлам.
- Архив Vosk проверяется по закреплённому SHA-256 и распаковывается во временную папку.
  Обход каталогов, ссылки, специальные имена и чрезмерный размер запрещены. Старая модель
  заменяется только после проверки новой, с откатом при ошибке замены.
- Исполняемая pickle-модель Silero проверяется по закреплённому SHA-256 перед загрузкой,
  включая уже существующий кэш. Загрузка публикуется атомарно после проверки.
- SAPI получает ответ как обычный текст, без автоматического исполнения XML-разметки речи.

Установленные пакеты сверены с базой OSV. Обновлены минимальные версии и локальные установки
Pillow (13.0.0), certifi (2026.10.23) и pip (26.2.2). Например:
[Pillow](https://osv.dev/vulnerability/GHSA-22hg-r758-rrw9),
[certifi](https://osv.dev/vulnerability/GHSA-6q48-6c7w-9gw2),
[pip](https://osv.dev/vulnerability/GHSA-4xh5-x5gv-qwph).

## Границы защиты

Капри работает с правами текущего пользователя Windows. Имя активации не является проверкой
личности: команды может произнести человек рядом или запись из динамиков. Не запускайте
ассистента от администратора. Настройки программ и сам исходный код считаются доверенными;
прямые команды пользователя могут запускать сохранённые приложения, включая терминал.

Обновления доверяют ветке `main` репозитория `TwKru/capri-reload` через HTTPS и закрепляют
скачивание за конкретным commit SHA. Отдельной подписи релизов нет: защита GitHub-аккаунта
и доступа на запись в репозиторий остаётся необходимой. SHA-256 моделей защищает от изменения
файла после закрепления версии и не заменяет независимый аудит кода модели.

Microsoft Edge TTS зависит от внешнего сервиса. Сетевые сбои по-прежнему могут вызвать переход
на голос Windows. Ошибки аудиоустройства больше не отключают онлайн-синтез; поздний сбой
фоновой предзагрузки не отменяет более свежий успешный синтез. Полностью исключить сбои сети
изменением локального кода нельзя.

Эта проверка и регрессионные тесты не являются гарантией отсутствия других уязвимостей.
