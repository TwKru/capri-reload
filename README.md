## Установка

**Нужно:** Windows 10 или 11, микрофон, интернет на время установки.

### 1. Установи Python
Скачай **Python 3.13**: [установщик для Windows (64-bit)](https://www.python.org/ftp/python/3.13.17/python-3.13.17-amd64.exe).
Подойдут и 3.11–3.14, все версии — на https://www.python.org/downloads/windows/
С Python 3.15 и новее голос Капри пока не работает. Если стоит только 3.15, `setup.bat` сам доставит 3.13 рядом.
При установке **обязательно поставь галочку «Add python.exe to PATH»**.

### 2. Скачай Капри
Зелёная кнопка **Code → Download ZIP** вверху страницы (или архив `capri.zip`, если получил его, например, в Telegram).
**Распакуй** архив в удобную папку, например `Документы\capri` — из архива запускать нельзя.

> Лучше, чтобы в пути к папке не было русских букв — так надёжнее работает распознавание речи.

### 3. Запусти `setup.bat`
Установит библиотеки и распакует офлайн-модель распознавания речи — она уже лежит в архиве Капри,
VPN не нужен. Дождись надписи «Готово».

> Если Windows покажет «Windows защитила ваш компьютер» — **«Подробнее» → «Выполнить в любом случае»**.
> Так Windows реагирует на любые .bat-файлы из интернета.

### 4. Запусти `run.bat`
Капри появится и поздоровается, в трее у часов появится её иконка.
Скажи **«Капри, открой ютуб»** — если открылось, всё работает.

> Windows может спросить доступ к микрофону — разреши. Нужный микрофон можно выбрать в меню трея → **«Микрофон»**.

## Как научить Капри разговаривать

Капри болтает через **[Ollama](https://ollama.com/download)** — бесплатную программу, которая запускает нейросеть прямо на компьютере.
Никаких ключей, подписок и отправки разговоров в интернет.

1. Запусти **`setup_ai.bat`** в папке Капри. Он сам:
   - установит Ollama, если её нет (или откроет страницу загрузки);
   - посмотрит на видеокарту и память и покажет только те модели, которые компьютер потянет, — от `qwen3:14b`
     (видеокарта от 12 ГБ) до `qwen3:1.7b` (совсем слабые ПК) — и посоветует подходящую.
     Можно согласиться (Enter) или выбрать номер;
   - скачает модель и пропишет её в настройки.
2. Перезапусти Капри (меню в трее → «Выход», затем `run.bat`).

> Если модель не качается — включи VPN и запусти `setup_ai.bat` ещё раз.

<details>
<summary><b>Вручную, без setup_ai.bat</b></summary>

Установи Ollama с https://ollama.com/download и в «Командной строке» скачай модель:

```
ollama pull qwen3:8b
ollama pull qwen3:0.6b
```

На слабом компьютере — `qwen3:4b-instruct` (именно `-instruct`: обычная `qwen3:4b` — «думающая» версия,
она проговаривает рассуждения вслух). Вписывать модель в `config.json` не нужно: если указанной там
модели нет, Капри при запуске сама возьмёт скачанную и запомнит её.
</details>

Свежие данные (погода, новости, курсы) нейросеть не знает — на такие вопросы Капри откроет поиск.

Короткие знакомые команды выполняются сразу. Свободные формулировки вроде «давай другую песню»
разбирает маленький диспетчер `qwen3:0.6b`; вопросы передаются большой модели.
По умолчанию диспетчер работает на процессоре, оставляя видеопамять разговорной модели и играм.
Если он не установлен или не ответил вовремя, обычные команды и разговор продолжают работать.

<details>
<summary><b>Вариант: Claude вместо локальной нейросети</b></summary>

Если есть ключ Anthropic API: в `config.json` поставь `"enable_ai": true` и впиши ключ в `"anthropic_api_key"`.
Claude умнее и видит свежие данные через веб-поиск, но это платно и через интернет.
</details>

## Обновления из GitHub

Источник обновлений — [TwKru/capri-reload](https://github.com/TwKru/capri-reload), ветка `main`.

- **«Капри, проверь обновления»** — проверить новую версию.
- **«Капри, обновись»** — скачать, установить и перезапустить Капри.
- Можно также запустить **`update.bat`** или воспользоваться пунктами обновления в меню трея.

Личные настройки `config.json`, модели распознавания, журналы и отчёты сохраняются.
Заменённые файлы остаются в `.capri-update-backup`; ошибка копирования вызывает откат.
Журнал установки — `capri-update.log`.

## Настройка

### Игровой режим

Капри автоматически замечает полноэкранное приложение на активном мониторе (проверка раз в две секунды).
В этом режиме она продолжает слушать имя, выполнять голосовые команды и показывать аватар.
Отрисовка ограничена примерно 30 кадрами/с, отключены полноэкранные молнии и случайные вспышки.
Фоновая предзагрузка озвучки приостанавливается, большая модель освобождает
видеопамять после завершения текущего запроса. Новые разговорные запросы в игре выполняются
на процессоре с двумя потоками, поэтому ответы большой модели могут быть медленнее.

После выхода из полноэкранного приложения обычный режим возвращается;
большая модель загрузится при следующем вопросе. Переключатель — **«Игровой режим автоматически»**
в меню трея; настройка в `config.json` — `"auto_game_mode": true`. Режим также срабатывает на
полноэкранное видео. Обычные развёрнутые окна с заголовком не считаются играми.
Игры в обычном окне автоматически не определяются. Сам игровой режим Капри не скрывает.

### Характер и настроение

Капри любопытная, немного колючая и доброжелательная. У неё пять состояний: спокойное,
довольное, обиженное, игривое и скучающее. Настроение видно в цвете статуса аватара,
а в покое — в его подписи. Оно меняет некоторые реплики на прогулку и жесты и тон ответов ИИ.

- **«Капри, ты молодец»**, **«спасибо»** — похвала и благодарность.
- **«Капри, ты тупая»** — коротко обидится. Обида сама проходит за полторы–четыре с половиной минуты.
- В подходящих готовых репликах примерно через раз встречается разговорный мат: например, «Готово. Заебись»
  или «Открываю … Погнали, блядь». Это отдельные варианты шаблонов: названия и числа не заменяются.
  Жёсткая брань в адрес пользователя появляется после прямого посыла вроде **«иди нахуй»**
  или трёх оскорблений подряд. Извинение или окончание обиды снимает этот резкий тон;
  редкие матерные вставки в обычных готовых репликах сохраняются.

В обычной беседе ИИ также разрешены уместные матерные междометия; личные оскорбления по-прежнему
зависят от сильной обиды. Ответы формируются законченными предложениями: пояснения в скобках,
десятичные числа и сокращения сохраняются, оборванные лимитом модели хвосты не озвучиваются.
В запрос ИИ передаются до четырёх предыдущих пар реплик и новый вопрос в пределах небольшого контекста; настройки генерации
уменьшают случайные формулировки и избыточный подбор синонимов.

Основной голос — **Маша из Kokoro-RU**, отдельной модели, дообученной на русском.
Используется компактный вариант ONNX q8 (модель около 138 МБ). Голос работает на CPU,
с двумя потоками, без сетевых запросов во время озвучки и без нагрузки на GPU.
Модель хранится в `%LOCALAPPDATA%\Capri\voice\kokoro-ru-masha-v2`.

Профиль Капри: высота **+3 полутона**, мягкая цифровая обработка **0,30** и редкие короткие
глитчи (**0,25**). Подъём высоты компенсируется скоростью синтеза, поэтому сама речь не ускоряется.
Глитч добавляет повтор примерно 30 мс звука и сохраняет весь исходный фрагмент;
на репликах короче 1,2 секунды глитчи отключены. Готовые короткие реплики кэшируются.
Все реплики, включая мат, проходят через один голос. В окне «Звук Капри»
высота и глитчи настраиваются отдельными ползунками.

Русский фонетический разбор использует словарные ударения eSpeak и правила произношения Kokoro-RU.
Отдельные тяжёлые нейросети расстановки ударений не загружаются; омографы и необычные имена
могут требовать уточнения ударения. Нативный синтезатор работает в отдельном скрытом процессе,
который освобождает память после пяти минут простоя. «Стоп» отменяет синтез и воспроизведение.

`setup.bat` устанавливает зависимости и голос. Для существующей установки можно отдельно
запустить `setup_voice.bat`, затем поставить `"tts_engine": "kokoro"`, `"kokoro_voice": "masha"`
в `config.json` и перезапустить Капри. Модель, голос и словарь закреплены на конкретной ревизии;
размеры и SHA-256 проверяются при установке и перед загрузкой. При обычном запуске скачиваний нет.

Исходная модель и голос: [zaakirio/kokoro-ru](https://huggingface.co/zaakirio/kokoro-ru), веса OpenRAIL.
Уведомления о заимствованных функциях произношения и их лицензиях — в [third_party/NOTICE.md](third_party/NOTICE.md).
Голос Windows остаётся запасным при сбое синтеза или воспроизведения и тоже изолирован.
Для возврата к онлайн-Светлане: `"tts_engine": "edge"` и перезапуск.
Старый английский тембр capri-desktop доступен с `"kokoro_voice": "capri"`, если его пакет уже установлен.

- **«Капри, извини»**, **«не обижайся»**, **«давай мириться»** — сразу примириться.
- **«Капри, ты вредина»**, **«я шучу»** — игривая реакция.
- **«Капри, как настроение?»**, **«ты обиделась?»**, **«тебе скучно?»** — ответ о текущем состоянии.
- **«Капри, расскажи шутку»**, **«мне скучно»** — быстрая местная реплика.

Настроение не мешает выполнять команды и не меняет значения громкости, выбор программы или
результаты действий. Названия песен, поисковые запросы и фразы с отрицанием не считаются
оскорблениями. В «извини, включи музыку» социальная часть меняет настроение, а команда выполняется.
Обычные команды остановки имеют прежний приоритет.

Эти реакции работают без ИИ и дополнительных сетевых запросов; в тестовом замере разбор
занимает несколько микросекунд, со сменой и сохранением состояния — около одной миллисекунды.
Синтез голоса занимает отдельное время. Готовые короткие фразы используют обычный кэш озвучки.
Спонтанные реплики характера тоже выбираются локально. В игровом режиме фоновой предзагрузки нет.

В `%LOCALAPPDATA%\Capri\personality.json` сохраняются только настроение, время его окончания
и небольшой счётчик повторной грубости. Тексты разговоров этот файл не содержит. Выключить характер
можно галочкой **«Характер и настроение»** в трее или настройкой `"personality": false`.

### Новые анимации

- **«Капри, походи»**, **«погуляй»**, **«пройдись»** — прогулка вдоль нижнего края экрана.
  Персонаж перебирает ногами, двигает руками и смотрит в сторону движения.
- **«Капри, покрутись»**, **«покружись»**, **«повернись»** — полный оборот.
  Иногда Капри также поворачивается сама, пока видна и свободна.
- **«Стоп»** — сразу остановить движение и прослушивание.
- **«Капри, заткнись / закройся / отвали»** — остановить ответ и скрыться без прощальной реплики.
  Решение принимается по законченной фразе: отрицания, цитаты и объяснения слов не скрывают Капри.
  Неоднозначные обращения проверяет маленькая локальная модель; пересказ чужих слов,
  условие и обращение к другой программе не считаются просьбой скрыться.
  При недоступной модели неоднозначная фраза не выполняет скрытие.

Если Капри сама задаёт вопрос, просит подтверждение или предлагает выбрать программу,
после окончания её речи можно ответить **без «Капри»**: например, «да», «нет», «второе».
Ожидание ответа — 8 секунд по умолчанию (`listen_window_seconds`); начатую фразу она дослушивает.
Окно принимает один ответ. Если ответ Капри содержит новый вопрос, открывается новое ожидание.
«Стоп» и тайм-аут закрывают окно и сбрасывают незавершённое подтверждение или выбор.
После обычной реплики без вопроса для новой команды снова нужно имя.

Имя проверяется по промежуточным результатам распознавания, без ожидания конца команды.
Микрофон передаёт звук порциями по 100 мс; при перебивании именем Капри сразу показывает режим прослушивания.

Для ходьбы и поворота добавлены по 16 новых нарисованных поз, включая боковые и задние ракурсы.
Промежуточное смешивание даёт по 96 кадров воспроизведения при 60 кадрах/с. Это смешивание
соседних рисунков, а не 96 независимо нарисованных поз. Кадры и промежуточные изображения
вычисляются по требованию с ограниченным кэшем. При ходьбе отключены случайные рывки и
зависания глитч-эффекта. В игровом режиме анимации по команде работают с ограничением примерно 30 кадров/с.

Из capri-desktop добавлены семь анимаций: живое ожидание, моргание, улыбка,
поза при перетаскивании, сон, пробуждение и танец.

- Проведи курсором по голове туда-сюда несколько раз — Капри улыбнётся, а настроение улучшится.
  Реакция имеет паузу в 6 секунд и не вызывает ИИ или озвучку.
- При перетаскивании она меняет позу; лёгкое дрожание мыши больше не отменяет обычный клик.
  После отпускания окно остаётся в рабочей области выбранного монитора.
- **«Капри, поспи»**, **«ложись спать»** — остаётся на экране спящей, без автоматического скрытия.
  Обращение по имени или клик сразу будит её. **«Капри, проснись»** — тоже работает.
- **«Капри, танцуй»**, **«потанцуй»** — танец на 12 секунд. «Стоп» его отменяет.
- В игре автоматическое моргание отключено, поза ожидания статична; ручные реакции доступны.
  Сон обновляется примерно 6 раз в секунду. Скрытый аватар останавливает таймер.

Ассеты загружаются лениво. Для новых клипов общий кэш содержит максимум одну декодированную
ленту спрайтов и восемь готовых кадров. Эти спрайты предоставлены Lachy из
[capri-desktop](https://github.com/lachydotmcg/capri-desktop) под **PolyForm Noncommercial 1.0.0**,
а не MIT; [условия и обязательное уведомление](assets/desktop_sprites/NOTICE.md).
Логика взаимодействия написана для текущего Qt-аватара.

Исходные листы — `assets/motion_sources/`, кадры — `assets/anim/walk/` и `assets/anim/spin/`.
Скрипт `tools/import_motion_sheets.py` повторно собирает кадры из готовых листов.

### Сокращения названий программ

Если сокращение не найдено локально, Капри ищет полное название в русской и английской Википедии,
сопоставляет результаты с установленными приложениями, играми Steam или звуковыми сессиями
и выполняет исходную команду. Например: **«Капри, замуть cs2»**, **«Капри, громкость cs2 30»**,
**«Капри, открой cs2»**. Для коротких русских сокращений проверяется и латинская запись: «кс два» → «кс2» → `CS2`.

При нескольких подходящих программах Капри просит назвать нужную. Если совпадения нет,
команда не выполняется. В интернет отправляется только название или сокращение;
найденные названия сохраняются в кэше на неделю. Поиск можно отключить: `"web_app_lookup": false` в `config.json`.

### Свои сайты и программы

Если Капри не знает нужный сайт или программу, научи её — проще всего голосом:

- **Сайт:** открой его в браузере и скажи **«Капри, запомни этот сайт как музыка»**.
- **Программу:** открой её, чтобы окно было на экране, и скажи **«Капри, запомни эту программу как запрет»**.
- Потом просто: **«Капри, открой музыка»**. Забыть: **«Капри, забудь сайт музыка»**.

Или через меню в трее → **«Мои сайты, программы и ответы…»**: там список всего, что Капри знает, и кнопки
«Добавить…» и «Удалить». Программа выбирается через обычное окно «Обзор» — путь вводить не нужно.

### Свои ответы

Можно научить Капри отвечать на любую фразу так, как хочешь:

- голосом: **«Капри, когда я скажу „как дела“, отвечай „лучше всех“»**;
- или в меню трея → «Мои сайты, программы и ответы…» → вкладка **«Ответы»**.

Фразу потом можно говорить чуть иначе — Капри всё равно узнает. Забыть: «Капри, забудь ответ на как дела».

значок в трее → **«Выход»**, затем снова `run.bat`.

| `voice_volume` | громкость голоса Капри `0`…`100`, общая громкость Windows не меняется; удобнее в меню трея → «Громкость Капри» |

## Если что-то не работает

<details>
<summary><b>Частые проблемы</b></summary>

| Проблема | Что сделать |
|---|---|
| Капри не слышит | выбери микрофон в меню трея → «Микрофон»; там же «Громкость и чувствительность…» — полоска должна заходить за розовую отметку, когда говоришь; проверь доступ к микрофону в настройках конфиденциальности Windows |
| Реагирует на шум или сама на себя | меню трея → «Микрофон» → «Громкость и чувствительность…» → убавь чувствительность |
| «Не найдена модель распознавания речи» | запусти `setup.bat` ещё раз; если в папке Капри нет папки `bundled` — скачай архив Капри заново и распакуй его полностью |
| Голос не Капри, а стандартный голос Windows | для Kokoro запусти `setup_voice.bat` и перезапусти Капри; для `tts_engine: "edge"` нужен интернет; если стоит Python 3.15, поставь Python 3.13 и запусти `setup.bat` ещё раз; если запущен **zapret** — Капри сама предложит добавить сервер голоса в его исключения (или добавь строку `bing.com` в `lists/list-exclude.txt` zapret) и перезапусти zapret |
| Отвечает только поиском в Google | запусти `setup_ai.bat`; проверь, что Ollama запущена (иконка ламы в трее) и в `config.json` стоит `"local_ai": true` |
| Перебивает сама себя | надень наушники или поставь `"barge_in": false` |
| Яркость не меняется | работает только на ноутбуках и мониторах с поддержкой DDC/CI |
| Не открывает программу | добавь её в `config.json` → `apps` (`"название": "путь\\к\\программе.exe"`) |
| Не находит чат в Telegram | нужен Telegram Desktop; называй чат так, как он подписан в списке |
| «Не смогла переключиться на окно» | кликни по нужному окну и повтори |
| `setup.bat` не находит Python | переустанови Python с галочкой «Add python.exe to PATH» |
| Что-то сломалось | подробности — в файле `capri.log` рядом с программой |
</details>

## Приватность

- Распознавание речи — офлайн (Vosk). С `use_google_stt` фраза после имени уточняется через Google.
- Основной голос Kokoro синтезируется локально. Если выбран `tts_engine: "edge"`, сервису Microsoft отправляется текст ответа Капри.
- Разговоры с Ollama не покидают компьютер. Журнал и отчёты хранятся только локально.
