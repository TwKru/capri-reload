# Colab: генерация голоса и эмоциональные вставки

Основной ноутбук — `reports/voice-colab/Capri_Colab_Voice.ipynb`.
Он генерирует произвольные реплики на GPU Colab по нынешнему образцу Capri 2.
Локально применяется одобренная обработка последнего примера: +0,8 полутона,
ускорение около 4,7%, непрерывный дубль 1,5 мс с уровнем 45%.
PyTorch-синтез может отличаться от GGUF; сначала проверьте голос.

Для длинных реплик первый фрагмент ограничен примерно 60 символами, остальные —
110 символами. Разделение сохраняет слова и отдаёт предпочтение границам предложений.
Следующий фрагмент синтезируется, пока проигрывается текущий. Это уменьшает объём
работы до первого звука; скорость генерации самой модели зависит от GPU Colab.

Запустите `benchmark_colab_voice.bat` для проверки текущего подключения без
воспроизведения. Результат — `reports/colab-speed/timings.json` и пробные WAV.
Клиент также пишет `Colab voice timing` в `capri.log` при обычном синтезе.
Новый сервер возвращает отдельно `generation_seconds` и `write_seconds`;
`transport_queue_seconds` — остаток времени запроса, включая очередь Gradio,
передачу и протокольные накладные расходы. Это не замер одной только сети.
На старой версии сервера доступны общая длительность запроса и локальная обработка.
Проверка выполняется без попадания текста реплик или пароля в файл измерений.

Для обновления сервера замените `colab_voice_server.py` на Drive версией из нового
пакета, перезапустите сессию Colab и снова выполните ячейки подключения/установки/
запуска. После появления новой ссылки обновите её через `connect_colab_voice.bat`.
Локальные изменения требуют перезапуска Капри. Чтение SSE допускает длительный
ответ модели; общий предел ожидания одной операции остаётся 180 секунд.

Запустите `prepare_voice_colab.bat`, откройте основной ноутбук в Colab, включите
GPU, выполните ячейки и загрузите `capri-voice-colab.zip`. Придумайте пароль
минимум из 12 символов. После появления HTTPS-ссылки `gradio.live` запустите
`connect_colab_voice.bat` на компьютере, введите ссылку и пароль, перезапустите Капри.
Инструмент проверяет подключение до изменения настроек. Для работы сессию Colab
нужно держать доступной. Пароль хранится локально в `config.json`, в Colab-пакет
конфигурация и другие API-ключи не включаются. В Colab передаются образец и тексты озвучки.

После завершения сессии запустите её снова и обновите ссылку той же командой.
Для возврата к локальной модели задайте `tts_engine: "qwen_clone"` в `config.json`
и перезапустите Капри. Кэш готовых коротких реплик сохраняется между подключениями.
Бесплатная сессия может завершаться при использовании через внешнее приложение;
ручной перезапуск не гарантирует доступность GPU и не снимает квоту Colab.

Библиотека эмоций использует настоящие короткие записи, а не чтение слова «смех».
Поместите фрагменты длиной 0,1–6 секунд в подпапки:

- `voicenew/emotions/giggle` — хихиканье;
- `voicenew/emotions/laugh` — смех;
- `voicenew/emotions/exclaim` — возглас;
- `voicenew/emotions/sigh` — вздох;
- `voicenew/emotions/gasp` — удивление.

Команда `py -m tools.install_emotions` подготовит их без обрезания окончаний.
Она также выполняется из `prepare_voice_colab.bat`. Затем перезапустите Капри.
Фразы, начинающиеся с «хи-хи», «хе-хе» или «ха-ха», используют запись соответствующей
эмоции, после неё произносится оставшийся текст. Поддерживаются также явные начальные
маркеры `[хихикает]`, `[смеётся]`, `[вздыхает]`, `[возглас]`, `[удивляется]`.
Рандомно выбирается один из имеющихся вариантов без немедленного повтора.
Отсутствующие эмоции автоматически не создаются. Эмоциональные записи не попадают в обучающий корпус.

## Отдельно: дообучение по новым фрагментам

Это необязательный этап: для переноса нынешнего голоса в Colab обучение не нужно.
Ноутбук `Capri_Voice_Lab.ipynb` предназначен для изменения голоса по новым записям.

1. Добавьте исходники в `C:\capricorn-main\voicenew`: WAV, MP3, FLAC, M4A,
   OGG, MP4 или WEBM. Нужны законченные отдельные реплики одного персонажа по
   1–15 секунд, желательно без музыки и других голосов. Файлы не обрезаются автоматически.
   Рядом можно положить одноимённый TXT с точной расшифровкой.
2. Запустите `prepare_voice_colab.bat`. Получится пакет
   `reports/voice-colab/capri-voice-colab.zip` и ноутбук
   `reports/voice-colab/Capri_Voice_Lab.ipynb`. Пакет содержит только корпус,
   инструменты и тексты реплик, без ключей и конфигурации приложения.
3. Откройте https://colab.research.google.com/ → «Загрузить блокнот» и выберите
   `Capri_Voice_Lab.ipynb`. Включите GPU и выполняйте ячейки по порядку.
   Подключение Google Drive потребует входа в ваш Google-аккаунт.
4. Загрузите ZIP в соответствующей ячейке. Автоматические расшифровки — черновики:
   исправьте их и отметьте `reviewed: true` в `corpus/corpus.json` на Drive.
   Проверка блокирует обучение при неподтверждённых текстах или проблемных записях.
5. Запустите дообучение. Используется исходная Qwen3-TTS 0.6B Base в PyTorch.
   Установленный Q8 GGUF не обучается и не заменяется. Результат обучения — CustomVoice
   с именем `capri`, доступный для генерации в ноутбуке.
6. Прослушайте результат и только затем экспортируйте библиотеку фраз. Тексты
   берутся из текущих заготовок без незаполненных шаблонов. Можно дополнить
   `phrases.json` любыми точными фразами. Генерация сохраняет каждую готовую запись;
   после обрыва повторный экспорт пропустит готовые записи той же модели.
7. Скачайте `capri-library.zip`, выполните в папке проекта:

   ```powershell
   py -m tools.install_voice_library "$env:USERPROFILE\Downloads\capri-library.zip"
   ```

   Перезапустите Капри. Совпадение по тексту и пробелам → готовая запись;
   неизвестная фраза → прежний локальный синтез. Регистр и пунктуация значимы.
   Тон +0,8 полутона, ускорение примерно 4,7% и дубль 1,5 мс применяются при
   воспроизведении, поэтому повторно запекать их в записи не нужно.

Библиотека хранится отдельно от очищаемого кэша в
`%LOCALAPPDATA%\Capri\voice-libraries`. Установка меняет только
`voice_library_path`. Чтобы отключить библиотеку, задайте для этого параметра
пустую строку в `config.json` и перезапустите Капри.

Снимок optimizer, модели и RNG сохраняется на Drive после каждой полной эпохи;
указатель `latest.json` обновляется после завершения записи. После обрыва подключите
Drive, установите зависимости и повторите ячейку обучения. Последняя незавершённая
эпоха начнётся заново. Для нового корпуса или других параметров используйте новый
`RUN_NAME`, чтобы не смешивать эксперименты. Полный снимок занимает несколько ГБ;
желательно 25–30 ГБ свободного Drive с учётом временного сосуществования снимков.

Ноутбук не поддерживает сессию искусственными кликами или перезапусками. Количество
перезапусков не отменяет квоту GPU и максимальную длительность сессии Colab.
Обученные веса автоматически не подключаются к локальному llama.cpp.
Чтобы использовать их для новых реплик в Colab, укажите папку модели в CHECKPOINT
основного ноутбука и обновите подключение на ПК.

не подтверждают качество будущего голоса или достаточность VRAM на выделенном GPU.
