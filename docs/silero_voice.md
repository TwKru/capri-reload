Голос Капри: Silero TTS v5

Выбран локальный русский Silero v5, голос Baya. Профиль по образцу из voicenew:
скорость 0,92, базовый pitch medium, сдвиг +0,5 полутона, лёгкий цифровой эффект 0,12.
Средняя высота в контрольной фразе составила 246 Гц. Это подбор параметров готового
голоса, а не обучение или клонирование диктора. Исходная запись не включается в архивы.

Windows-сборка включает CPU-версию PyTorch, SciPy и модель v5_ru.pt. Интернет для
синтеза не нужен. Для запуска из исходников сначала выполни setup_voice.bat;
он устанавливает requirements-voice.txt и активирует профиль. Старая озвучка Edge
остаётся аварийным резервом с записью причины в журнал.

Модель проверяется по SHA256 до загрузки. Синтез сериализован, длинный текст разбивается
на небольшие фрагменты, отмена проверяется между ними. Кэш учитывает модель v5,
диктора, высоту, скорость и эффекты. Громкость и эффекты можно менять в окне звука.

Доступная запись для проверки: reports/silero-v5/capri-v5.wav.
Модель и лицензия: https://github.com/snakers4/silero-models
