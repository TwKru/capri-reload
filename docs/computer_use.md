# Computer Use

Капри поддерживает нативный OpenAI computer tool отдельно от модели общения.

1. Запусти обновлённые исходники через `run.bat`.
2. Открой MAINFRAME → Задания. Введи ключ OpenAI API (или задай `OPENAI_API_KEY`)
   и модель с поддержкой computer tool. По умолчанию: `gpt-6.1-sol`.
   Нажми «Сохранить настройки Computer Use».
3. Включи «Разрешить снимки и клики агента для заданий». Это общий доступ к экрану для агентов.
4. Выбери исполнителя «Computer Use — OpenAI», опиши результат и добавь задачу.
   Можно использовать голосовую или текстовую команду:
   `управляй компьютером: открой Блокнот и введи привет`.

Капри получает снимок главного монитора, выполняет предложенные клики, ввод,
сочетания клавиш, прокрутку и перетаскивание, затем снова смотрит на экран.
Координаты пересчитываются с учётом масштаба Windows. Другие мониторы не захватываются.
Общение и старые задания продолжают использовать ранее выбранную нейросеть.

Остановка: Escape, голосовая команда «Капри, стоп» или «Пауза» в заданиях.
Журнал, лимит времени и лимит действий находятся на вкладке «Задания».
На паузе или после перезапуска агент начинает новый сеанс с текущего экрана и
краткой записью выполненных действий. Поэтому явно указывай конечный результат,
чтобы он мог проверить уже сделанное и не повторять действия.

Если API требует подтверждения, задание получает статус «Нужно разрешение».
Посмотри показанный вызов и используй существующую кнопку разрешения шага.
После перезапуска неподтверждённый вызов не восстанавливается: создай новое задание.

Снимки отправляются в OpenAI только во время явно созданного задания, хранятся
в памяти текущего запуска и не записываются в журнал/SQLite. Запросы используют
`store: false`; история диалога computer tool передаётся приложением в памяти.
Ключ сохраняется в существующем `config.json`. Не публикуй этот файл.
Требуются интернет, доступ к выбранной модели и средства на API-счёте.
Ошибка ключа, модели или сети отражается в результате задания, без выполнения
неполученных действий. Содержимое экрана не считается указанием пользователя.

Протокол: https://developers.openai.com/api/docs/guides/tools-computer-use
