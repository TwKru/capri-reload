# Capri: MAINFRAME и новые возможности

Открой **MAINFRAME — управление Капри** через правый клик по значку чипа в трее. Команды «открой MAINFRAME», «открой задания» и «открой расписание» открывают ту же панель. Озвучка существующего проекта не заменена.

## Нейросети

В меню «Нейросеть и API» доступны OpenAI, Google AI Studio/Gemini, NVIDIA NIM, DeepSeek, Claude/Anthropic, Ollama и локальный GGUF через llama.cpp. Ключи и модели провайдеров сохраняются отдельно. В API-режимах Ollama не создаётся и не прогревается; ошибки API не переключают приложение на локальную модель.

Обычные команды разбираются на компьютере. Короткий ответ API ограничен 160 выходными токенами, подробный — 384. Контекст беседы ограничен; память не отправляется целиком. Поиск выполняет приложение, а найденные фрагменты передаются модели. Планы заданий отключены по умолчанию: их можно включить ценой одного дополнительного запроса на задание.

В MAINFRAME → «Локальные модели» можно скачать llama.cpp и Qwen3 4B, Gemma 4 E2B или Gemma 4 E4B. Загрузка начинается по кнопке, требует примерно 2,5–4,6 ГБ плюс ~560 МБ для зрения Gemma и проверяется по закреплённому SHA256. Свои пути к llama-server, GGUF и mmproj также поддерживаются. Сервер запускается при первом запросе, слушает только 127.0.0.1 и завершается при смене режима или выходе. Для Ollama со зрением нужна установленная мультимодальная модель.

## Память и личность

`memory.json` содержит факты и ограниченную историю. История очищается через 7 дней; старые записи без даты получают дату при миграции. Факты не имеют недельного срока. Ключи и пароли не сохраняются как факты.

`me.md` содержит рукописные заметки и синхронизируемый блок запомненных фактов. Его можно редактировать в MAINFRAME. «Очисти память» очищает историю, факты и заметки. `personality.md` перечитывается перед каждым ответом, поэтому изменения действуют без перезапуска. Сброс личности сохраняет прежний текст в `personality.backup.md`. Неизменённая личность не увеличивает экономный API-промпт. Выбор языка распространяется на ответы модели; доступно 20 языков. Обращение по имени или прозвищу задаётся в прежнем окне профиля.

Эти файлы, `config.json` с ключами и база `jobs.sqlite` исключены из исходных релизов, синхронизации GitHub и установщика; обновление их не заменяет.

## Рабочий стол

Перетащи Капри к верхней границе окна или значка. Она прицепится к опоре и будет следовать за окном. Shift при отпускании сохраняет выбранное положение, Ctrl оставляет её висеть. «Сядь на окно», «сядь на курсор» и «отцепись» работают без модели. В MAINFRAME доступны переноска на курсоре, смена окна, размер, прогулка и сон. Гладь голову движениями мыши из стороны в сторону.

Губы двигаются при речи; стоячая поза с морганием используется для разговора, лежачая остаётся обычной позой ожидания. Автоматический танец можно включить отдельно: он использует системную медиасессию и пики выходного звука, без записи микрофона.

Глобальные клавиши Windows настраиваются в MAINFRAME. По умолчанию: Ctrl+Alt+V — позвать, Ctrl+Alt+N — микрофон, Ctrl+Alt+T — текст, Ctrl+Alt+H — скрыть, Ctrl+Alt+C — отцепить. Escape останавливает выполняемое задание. Занятые сочетания отображаются в настройках.

## Экран и задания

«Что на экране?» или «посмотри экран» передаёт один снимок выбранной модели. Фоновое наблюдение и использование экрана агентом — два отдельных переключателя, оба выключены по умолчанию. Снимки уменьшаются до 960 пикселей, кодируются в JPEG и остаются в памяти. Наблюдение не вызывает API для неизменившегося изображения и работает не чаще раза в минуту, по умолчанию раз в пять минут. Модель должна поддерживать изображения.

На вкладке «Файлы» выбери текстовые файлы до 1 МБ. Можно читать и редактировать их вручную или дать задание модели. Перед записью проверяется, что файл не изменился после чтения; предыдущая версия сохраняется рядом с суффиксом `.capri-backup`. Для неё есть кнопка восстановления. Произвольные файлы вне выбранного списка агенту недоступны.

Создай задание в MAINFRAME или скажи **«выполни задачу: …»**. Задай время старта, повтор, число шагов и лимит времени. Поддерживаются задания до 12 часов и 500 шагов на запуск; компьютер и Capri должны оставаться включёнными. Приложение не будит компьютер из сна. Задание выполняется последовательно: наблюдение, следующий шаг, результат, запись журнала. Доступны клики, ввод текста, сочетания клавиш, прокрутка, открытие приложений и сайтов, чтение и правка выбранных файлов. Произвольные команды shell не предоставляются модели.

При работе виден указатель CAPRI. Escape, «стоп» или кнопка паузы отменяют текущий запрос и следующие действия. Уже выполненные действия не откатываются. Журнал и прогресс сохраняются в SQLite; после перезапуска прерванная работа остаётся на паузе и продолжается по кнопке. Повторы сохраняют первоначальное время старта, пропуская уже прошедшие интервалы. Будущий запуск можно поставить на паузу; возобновление не запускает его раньше выбранного времени. Кнопка отмены отключает задание и все его дальнейшие повторы. Заблокированный чувствительный шаг можно просмотреть целиком и отдельно разрешить; после изменения экрана он не выполняется по старым координатам.

## Распознавание речи

Существующий Vosk остаётся вариантом по умолчанию. Дополнительно можно выбрать Windows Speech с установленным речевым пакетом или локальный Parakeet через Sherpa-ONNX. Для Parakeet нужны `sherpa-onnx` и совместимая папка `encoder*.onnx`, `decoder*.onnx`, `joiner*.onnx`, `tokens.txt`. Языки зависят от конкретной модели. Если Parakeet недоступен, используется Vosk. Эти настройки применяются после перезапуска. Синтез голоса не менялся.

## Сборка и платформы

`python tools/build_desktop.py` создаёт `dist/Capri/Capri.exe` и `dist/Capri-Windows.zip` с Python и Qt внутри. Для сборки нужен PyInstaller. Установщик собирается Inno Setup 6 из `tools/capri_installer.iss`, устанавливается в профиль пользователя и не требует прав администратора. На чистом запуске EXE предлагает API-режим и распаковывает проверенную офлайн-модель Vosk. Дополнительные движки озвучки сохраняют свои прежние требования; перенос новых голосовых движков в задачу не входил.

Обновление EXE использует только автономный ZIP из GitHub Releases с контрольной суммой GitHub. Пока такой файл не опубликован, приложение сообщает, что автономного обновления нет. Исходный ZIP не устанавливается поверх EXE. Для исходников сохраняется прежний механизм обновления. Автозапуск Windows включается отдельным переключателем.

`python main.py` выбирает Windows-приложение либо ограниченный переносимый режим на macOS/Linux: текстовый диалог, API/Ollama/GGUF, память, MAINFRAME, файловые задания и просмотр экрана с разрешениями ОС. На X11 для опор нужен `wmctrl`. Глобальные клавиши и ввод агента в этом режиме пока Windows-only; macOS и Linux не проверялись на реальных машинах. Их сборки нужно создавать на соответствующей ОС. Windows-сборка не имеет коммерческой цифровой подписи; сертификат подписи и Apple notarization в репозитории отсутствуют.

Самопроверка без модели, микрофона и платных запросов: `python main.py --smoke-test reports/smoke` с `QT_QPA_PLATFORM=offscreen`. У собранного EXE есть тот же параметр. Тесты: `python -m unittest discover -s tests -q`.
