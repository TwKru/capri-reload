# Графическая установка Windows

Запустите `Capri-Windows-Setup.exe`. Python и консоль не требуются.
Установка выполняется для текущего пользователя без прав администратора.

В установщике можно выбрать режим:

- **Локальный ИИ**: мастер загрузит выбранную GGUF-модель и движок llama.cpp.
  Базовый вариант Qwen3 4B занимает около 2,5 ГБ; другие варианты крупнее.
  Есть индикатор загрузки, проверка размера и SHA-256. Для первоначальной загрузки
  нужен интернет. Ollama отдельно устанавливать не нужно.
- **Облачный API**: выберите OpenAI, Google Gemini, NVIDIA NIM, DeepSeek или
  Anthropic, укажите ключ и модель. Поле ключа скрыто, его можно показать флажком.
  Сохранение не отправляет тестовых платных запросов; ключ используется при первом
  обращении к ИИ. Тарификация и доступность модели зависят от сервиса.

После копирования файлов откроется мастер подключения в оформлении Капри.
Отмена загрузки не включает недокачанную модель и не стирает прежние настройки.
Если первая настройка отменена, она появится при следующем запуске.

При обновлении настройки, память, ключи других сервисов и параметры голоса
сохраняются. Установщик не содержит личных ключей разработчика. Режим ИИ можно
поменять в настройках, повторный мастер запускается командой `Capri.exe --setup`.
Быстрый голос Silero и сгенерированные смешки/фырканье входят в пакет.

Сборка с Inno Setup 6.6 или новее:

```powershell
py -m tools.build_installer_art
py -m tools.build_desktop --dist-dir build/installer-dist
& "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe" /DAppSource="C:\capricorn-main\build\installer-dist\Capri" tools/capri_installer.iss
```

Готовый EXE находится в `dist/Capri-Windows-Setup.exe`.
Сборка в отдельной папке не затрагивает настройки старой переносимой версии.
