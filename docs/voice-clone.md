# Голос по своим записям — вариант B

Qwen3-TTS 0.6B Q8 клонирует голос по всем уникальным записям из `voicenew`.
После синтеза применяются согласованные по времени голосовые слои и эквализация
по спектру записей. Используется отдельный процесс на CPU с низким приоритетом,
шестью потоками. Применяется исходный генератор `llama-tts`, который точно
воспроизводит выбранный образец B. Серверный маршрут давал другой голос.
Синтез не обращается к платным API. API-режим чата продолжает работать отдельно.

Установленные файлы лежат в `%LOCALAPPDATA%\Capri\voice\qwen3-b12069`.
Образцы и профиль голоса остаются на этом компьютере и не входят в сборку.

Для установки из исходников положите проверенный CPU runtime llama.cpp b12069
и две модели в `models/qwen-tts`, свои записи в `voicenew`, затем запустите
`setup_clone_voice.bat`. Установщик сверяет SHA-256 всех исполняемых файлов и моделей.
Он не скачивает и не исполняет произвольные модели из интернета.

Источники файлов:

- Runtime: https://github.com/ggml-org/llama.cpp/releases/tag/b12069
  (`llama-b12069-bin-win-cpu-x64.zip`, SHA-256
  `5658d79020c5b6a32f1e267c548383942d7c6c1784814f23b9da33d1f4eb0ff2`).
- Модели: https://huggingface.co/mradermacher/Qwen3-TTS-12Hz-0.6B-Base-GGUF/tree/0762b31e9cd99274d49dca4e895bd81863134f08
  (`Qwen3-TTS-12Hz-0.6B-Base.Q8_0.gguf` и
  `Qwen3-TTS-12Hz-0.6B-Base.mmproj-Q8_0.gguf`).

В личном `config.json`: `tts_engine` = `qwen_clone`, `qwen_threads` = `6`.
Для исходного звучания B дополнительные `voice_fx`, `voice_shift`, `voice_glitch`
должны быть равны нулю. Обработка B уже включена в этот движок.
Громкость меняется обычным ползунком Капри.
Вернуться к прежнему голосу можно через `tts_engine` = `silero`.

Генератор загружает модель для новой фразы; повторные короткие реплики берутся
из файлового кэша. Длинные ответы озвучиваются по предложениям с подготовкой
следующего фрагмента во время воспроизведения. На CPU новые фразы могут
генерироваться медленнее реального времени. Первое включение требует загрузки
модели; подготовленная реплика «Слушаю…» воспроизводится из кэша.
Прерывание речи останавливает и воспроизведение, и генерацию.
После запуска проверяются файлы модели и загружается обработка звука. Фоновая генерация
набора стандартных ответов для Qwen отключена: она занимала единственный процесс
синтеза перед ответом пользователю. В потоке ответа ИИ следующая реплика также
не запускает синтез впереди первой. Кэш готовых коротких реплик сохраняется.

Шумогейт приглушает фон только в паузах. Во время слов исходная эквализация B,
высота и спектр речи сохранены; запас 70 мс защищает согласные и окончания.
Спектральная очистка речи отключена, поскольку меняла воспринимаемый тембр.
Версия кэша изменена, чтобы прежняя обработка не воспроизводилась.

Диагностика без микрофона, воспроизведения и облачных запросов:
`Capri.exe --clone-tts-test reports\clone-test`.
